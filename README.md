Project Overview

This project performs customer segmentation using the K-Means clustering algorithm as part of an AI & ML Internship task. The goal is to group customers based on their purchasing behavior to help businesses make data-driven decisions.

🎯 Objective

Apply K-Means clustering on customer data.

Identify optimal number of clusters using the Elbow Method.

Visualize customer segments.

Export segmented dataset.

📊 Dataset

Source: Mall Customer Segmentation Dataset (Kaggle)

Features Used:

Annual Income (k$)

Spending Score (1–100)

🛠 Tools & Technologies

Python

Pandas

Scikit-learn

Matplotlib

Seaborn

⚙️ Methodology

Loaded and cleaned the dataset.

Removed irrelevant columns.

Scaled the data using StandardScaler.

Used the Elbow Method to determine optimal K.

Trained the K-Means model.

Visualized clusters.

Saved the segmented dataset.

📈 Results

Optimal number of clusters: 5

Customers were segmented into:

Budget customers

Premium customers

Careful customers

Impulsive buyers

Average customers
